# `runtime/` — the Rust runtime

6 files, 680 lines. Copy them **directly into `src/parser/`** — not into a
subdirectory. They refer to `crate::parser::...`, so the location is part of
the contract.

```bash
cp tibineko/runtime/*.rs src/parser/
```

Then add the `mod` declarations from
[`../seed/parser_mod_snippet.rs`](../seed/parser_mod_snippet.rs).

## What each file gives you

### `base_parser.rs` — `trait BaseParser`

The whole generated parser is written against this. Nothing in `gen/` emits a
concrete parser; it emits a trait whose default methods call these.

```
type Error: IParseErr;

peek::<N>()            lookahead, N = 0 or 1
consume_token()
expect(&Token)
repeat<T>()            zero or more, with FIRST_2 lookahead
optional<T>() / optional_box<T>()
alloc<T>() / alloc_box<T>()
backtrack<T>() / backtrack_clean<T>()
report_error()
enviroment() / now_span()
is_panic_or_backtrack_mode() / set_panic_or_backtrack_mode()
```

Also defines `struct Enviroment` — misspelled upstream, kept misspelled
deliberately, because renaming it would break every consumer's `impl` block.

### `ast_node.rs` — `trait ASTNode` and `TokenSet`

`ASTNode` is implemented by every generated node. It carries the FIRST/FOLLOW
sets as `TokenSet`s and exposes the predicates the generated `repeat` and the
recovery code use: `is_first1_sets`, `is_first2_sets`, `is_follow_sets`,
`is_sync_point`, plus `ast_name()` for the tracer.

`TokenSet` stores membership as three `u64` bitmasks and an `any` flag (set by
`Token::Invalid`). It ships its own `#[cfg(test)]` tests, which run as part of
your crate's `cargo test --lib`.

### `errors.rs` — `ParseErr`, `trait IParseErr`

`IParseErr::build(identifier, expected, found)` is what the generated code
calls to construct an error. It is a **trait** method, so
`manual_parser.rs` needs `use crate::parser::errors::IParseErr;` in scope or
`Self::Error::build` does not resolve. See
[`../docs/gotchas.md`](../docs/gotchas.md) §1.

### `recovery.rs` — panic-mode recovery

One free function, `recover(...)`. On error it skips forward to the next
FIRST/FOLLOW synchronization point rather than abandoning the parse, which is
why a broken entry does not lose the rest of the document.

### `tracer.rs` — `trait Tracer`

```rust
pub trait Tracer: Sized {
    type Guard;
    fn enter(name: &'static str);
    fn leave(name: &'static str);
    fn trace(name: &'static str) -> Self::Guard;
}
```

`NopeTracer` compiles to nothing; `LogTracer` prints. The generated parser is
generic over `TR: Tracer`, so tracing is a zero-cost choice per instantiation.

### `token_stream.rs` — the reference token cursor

`new`, `peek(index)`, `checkpoint` / `rollback` / `commit` for backtracking,
`is_eof`, `get_now_span`, and an `Iterator` impl yielding `(Token, Span)`.

Replaceable if you already have one — the generated parser only reaches it
through `BaseParser`.

## What you must provide

The runtime is deliberately not generic over these — that is the whole point of
vendoring rather than publishing a crate.

```
crate::compiler::arena::{Arena, ArenaBox, ArenaIter}
crate::compiler::span::Span
crate::diagnostic::stream::DiagnosticStream
crate::tokenizer::tokens::{Token, Comment, Keyword, Operator, Delimiter}
crate::parser::generated_ast::ASTVisitor   (generated by tibineko)
crate::parser::parse::Parser               (yours; start from seed/parse.rs)
```

`example/src/compiler/` and `example/src/diagnostic/` are working
implementations of the first four.

## Constraints worth knowing

**`Token` shape.** `TokenSet` stores membership as three `u64` bitmasks indexed
by `keyword as u8`, `operator as u8`, `delimiter as u8`. So those three enums
must be `#[repr(u8)]`, have fewer than 64 variants each, and keep a stable
order — the bitmask and the token map are only in sync if the discriminants do
not move. **Nothing checks this.** Past 64 variants, widen `TokenSet` to
`u128` in your copy.

**`ASTNode` bounds.** Generated nodes are `Copy + Clone + Debug + Hash +
PartialEq + Eq + 'static + Sized`. Keeping AST nodes small is why lists are
`ArenaIter` and recursive edges are `ArenaBox`. `check_ast_size.ts` exists to
catch a struct that grew past a cache line.

**`ArenaIterReader::Item` is `&mut T`.** The arena iterator hands out mutable
references, not values. Since the nodes are `Copy`, `.map(|e| *e)` at the point
of collection is the clean fix. See
[`../docs/gotchas.md`](../docs/gotchas.md) §4.

**Comment filtering.** `token_stream.rs` drops `Comment::LineComment` and
`Comment::BlockComment` on construction — the tokenizer does not. A comment
variant you *do* want the parser to see must be a different variant.

## Provenance

Five of the six are byte-identical to hydent-lang `bb9a359`, which compiles and
passes its tests:

| File | Upstream path | Status |
|---|---|---|
| `ast_node.rs` | `src/parser/ast_node.rs` | identical |
| `base_parser.rs` | `src/parser/base_parser.rs` | identical |
| `errors.rs` | `src/parser/errors.rs` | identical |
| `recovery.rs` | `src/parser/recovery.rs` | identical |
| `token_stream.rs` | `src/tokenizer/token_stream.rs` | identical |
| `tracer.rs` | `src/parser/tracer.rs` | drops `use std::{fmt, io};` and `use crate::compiler::span::Span;` |

Note that `token_stream.rs` lives under hydent's *tokenizer*, not its parser;
tibineko moves it to `src/parser/` because the runtime's paths expect it there.

The `tracer.rs` imports are unused — hydent masks that with a crate-level
`#![allow(unused)]`. Dropping them keeps the file clean under
`clippy -D warnings` without needing an allow.

## Keeping clippy quiet

The runtime is a general-purpose library and a small consumer uses part of it,
so `dead_code` is expected rather than a defect. Silence it **on the module
declarations** in your `src/parser/mod.rs`, not inside these files, so T1 stays
byte-identical to upstream:

```rust
#[allow(unused_mut, dead_code)]
mod base_parser;
#[allow(unused_variables, dead_code)]
mod errors;
```

`example/src/parser/mod.rs` has the full set.
