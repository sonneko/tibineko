# `runtime/` — the Rust runtime

684 lines. Copy these files **directly into `src/parser/`** — not into a
subdirectory. They refer to `crate::parser::...`, so the location is part of
the contract.

```bash
cp tibineko/runtime/*.rs src/parser/
```

Then add the `mod` declarations from `seed/parser_mod_snippet.rs`.

## What each file gives you

| File | Provides |
|---|---|
| `base_parser.rs` | `trait BaseParser` — `peek`, `expect`, `repeat`, `alloc_box`, `optional`, `backtrack`, `backtrack_clean`, `report_error`. The generated parser is written entirely against this. |
| `ast_node.rs` | `trait ASTNode` (FIRST/FOLLOW sets per node) and `TokenSet`, the `u64` bitmask used for token membership. |
| `errors.rs` | `ParseErr` and `trait IParseErr`. |
| `recovery.rs` | Panic-mode recovery: skip forward to the next FIRST/FOLLOW synchronization point. |
| `tracer.rs` | `trait Tracer` — opt-in parse tracing. `NopeTracer` compiles to nothing. |
| `token_stream.rs` | A reference token cursor with `checkpoint` / `rollback` / `commit` for backtracking. Replaceable if you already have one. |

## What you must provide

The runtime is deliberately not generic over these — that is the whole point of
vendoring rather than publishing a crate.

```
crate::compiler::arena::{Arena, ArenaBox, ArenaIter}
crate::compiler::span::Span
crate::diagnostic::stream::DiagnosticStream
crate::tokenizer::tokens::{Token, Comment, Keyword, Operator, Delimiter}
crate::parser::generated_ast::ASTVisitor   (generated by tibineko)
crate::parser::parse::Parser               (yours; start from seed/parse.rs)
```

## Constraints worth knowing

**`Token` shape.** `TokenSet` stores membership as three `u64` bitmasks indexed
by `keyword as u8`, `operator as u8`, `delimiter as u8`. So those three enums
must be `#[repr(u8)]`, have fewer than 64 variants each, and keep a stable
order — the bitmask and the token map are only in sync if the discriminants do
not move. Past 64 variants, widen `TokenSet` to `u128` in your copy.

**`ASTNode` bounds.** Generated nodes are `Copy + Clone + Debug + Hash +
PartialEq + Eq + 'static + Sized`. Keeping AST nodes small is why lists are
`ArenaIter` and recursive edges are `ArenaBox`. `check_ast_size.ts` exists to
catch a struct that grew past a cache line.

**Comment filtering.** `token_stream.rs` drops `Comment::LineComment` and
`Comment::BlockComment` on construction. A comment variant you *do* want the
parser to see (hydent-lang's doc comments, for instance) must be a different
variant.
